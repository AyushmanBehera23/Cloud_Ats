# Auth Service

> Registration, Login, JWT token management, Role-Based Access Control

**Port:** 8081  
**Schema:** `auth_schema`  
**Status:** 🔲 Not yet implemented (Prompt 1)

## Planned Features
- User entity with roles: CANDIDATE, RECRUITER, ADMIN
- Registration & login with BCrypt password hashing
- JWT access token + refresh token lifecycle
- Logout (token revocation)
- Forgot password flow
- Spring Security configuration
- Role-based endpoint protection
- Flyway migrations + seed data
- Swagger/OpenAPI documentation
