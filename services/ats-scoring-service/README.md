# ATS Scoring Service

> Rule-based resume scoring with specialization and JD comparison modes

**Port:** 8083  
**Schema:** `scoring_schema`  
**Status:** 🔲 Not yet implemented (Prompt 3)

## Planned Features
- Rule-based scoring across: skills, projects, experience, education, certifications, formatting, keywords
- 9 specialization modes with distinct weighted criteria
- Job Description comparison mode with match %, skill gap analysis
- Structured output: overall score, matched/missing skills, suggestions
- Consumes parsed resume data from resume-service API
