# Resume Service

> Upload, parse, store, and manage candidate resumes

**Port:** 8082  
**Schema:** `resume_schema`  
**Status:** 🔲 Not yet implemented (Prompt 2)

## Planned Features
- Resume upload (PDF/DOCX, size-limited)
- File storage in MinIO (S3-compatible)
- Resume parsing: name, email, phone, LinkedIn, GitHub, skills, projects, education, experience, certifications
- Resume history and versioning
- Secure download URL generation
- Delete and preview endpoints
- JWT validation via auth-service
